개인정보처리방침 (Privacy Policy)

시행일 / Effective: 2026-10-27

밤의 파일 업로더(이하 "이 도구")는 YouTube 채널 "밤의 파일" 운영자 본인만 사용하는 개인용 업로드 도구입니다.

1. 사용하는 정보

  • 운영자가 Google 로그인으로 허용한 YouTube 계정 권한(youtube.upload, youtube.readonly)만 사용합니다.
  • 읽는 정보: 운영자 채널의 이름, 업로드 재생목록에 있는 영상의 제목과 공개(예정) 시간.
  • 쓰는 정보: 운영자가 만든 영상, 제목, 설명, 태그, 썸네일, 공개 예약 시간.

2. 저장과 공유

  • 로그인 토큰과 업로드 기록은 운영자 본인의 컴퓨터에만 저장되며, 외부 서버로 보내지 않습니다.
  • Google API로 받은 정보를 제3자에게 판매하거나 공유하지 않으며, 광고나 다른 목적으로 사용하지 않습니다.
  • 이 도구는 운영자 외의 다른 사용자 데이터를 수집하지 않습니다.

3. Google API 서비스 사용자 데이터 정책

이 도구가 Google API에서 받은 정보를 사용하는 방식은 제한된 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 도구는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받는 YouTube API 서비스를 사용합니다.

4. 권한 철회

언제든지 Google 계정의 보안 설정에서 이 도구의 접근 권한을 철회할 수 있습니다.

English summary

This tool is used only by the channel owner. It uses the owner's YouTube permissions to read the owner's recent video titles and schedules and to upload the owner's own videos and thumbnails. Tokens and logs stay on the owner's computer. No data is sold or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
