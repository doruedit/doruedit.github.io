밤의 파일 업로더 (Night File Uploader)

밤의 파일 업로더는 YouTube 채널 밤의 파일(@about_night_file) 운영자가 자신이 만든 쇼츠 영상을 자기 채널에 예약 업로드하기 위해 쓰는 개인용 도구입니다.

Night File Uploader is a personal tool used only by the owner of the YouTube channel "밤의 파일" to upload and schedule the owner's own Shorts videos, titles, descriptions, tags and thumbnails through the YouTube Data API.

하는 일 / What it does

  • 채널 운영자의 컴퓨터에 있는 영상 파일과 썸네일을 운영자 본인의 YouTube 채널에 업로드하고 공개 시간을 예약합니다.
  • 중복 업로드를 막기 위해 운영자 채널의 최근 영상 제목과 공개 예정 시간을 읽습니다.
  • 다른 사용자의 데이터는 수집하거나 사용하지 않습니다.
